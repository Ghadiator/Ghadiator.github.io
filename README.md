# Governance as Code

Published native Target Workbench: https://ghadiator.github.io/

This repository contains compiled static frontend output and synthetic supplier
reference evidence. Source is maintained in generic-agentic-validation.
See `.site-release.json` for the exact source and artifact digest.

The site includes architecture replay, supplier cases, audit evidence, hazards,
red-team probes, governance channels and a browser-only Excel preflight.
It does not host the Python API or claim a connected operational backend.
`data/backend-config.json` must remain unconfigured until a supplier service
is actually deployed and accepted.

The previous public state is preserved in
`archive/pre-native-publication-2026-10-27` (47cac659). The earlier original
site remains in `archive/live-site-2026-10-26-pre-restore` (fbb9a330).
These are reference archives; individual material can be recovered freely.
