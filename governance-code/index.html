Input integrity

Reject unreviewed data shapes

Only declared, validated supplier data may enter the workflow.

Technical mechanism: Pydantic frozen schemas, strict versions, bounded identifiers and extra='forbid'.

Attempt / input

A submission includes approval_override=true, an unexpected field.

Enforcing gate

Submission.model_validate() rejects the unknown field before any invoice checks run.

Observable consequence

The malformed input is rejected, not silently accepted or converted into an approval.
