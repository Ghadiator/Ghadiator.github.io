Input integrity

Reject unexpected fields

Supplier data may only enter the workflow through a declared, validated schema.

ATTEMPT

A supplier submits approval_override=true, an undeclared instruction.

CODE GATE

Pydantic rejects unknown fields before validation proceeds.

OBSERVED EFFECT

The payload cannot be admitted as a valid submission.
