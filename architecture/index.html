Committee routes are evidence-dependent

4/15 cases record both arguments with structured Opponent CoVe; 2/15 record Proponent alone after proposal admission failed; 9/15 never entered the committee. The historic supplier runner does not independently verify the Proponent narrative.

How to explore: four purposes over one canvas. Learn the data contracts, follow the workflow, replay a recorded case, or run your own.

Why does this matter?

Typed contracts stop malformed data at the boundary.

The workbook loader returns a frozen input model or fails. Tier 1 receives only that model and returns a Tier1Result. Tier 2 adds the approved baseline and returns a Tier2Result. The committee works on VCDeps and hands back a JudgeVerdict. Every hand-off is a declared type, so a block cannot pass on a field the next block does not expect.

Pydantic does

Types · fields · declared constraints · structured hand-off

It does not

Prove facts · check arithmetic · verify a model's claim. The tier checks do that.
