How the two parts fit together

  1. Explore here. The architecture, case library and evidence are served by GitHub Pages.
  2. Work in the supplier service. The existing service uses a reviewer session, protected uploads and owner-scoped cases.
  3. Review with a person. The service checks the current case revision and records the human decision with its rationale.

The supplier service and the older reviewer API have different contracts. This site does not connect the recorded examples to an unrelated API or treat a successful health check as proof that operations are available.
