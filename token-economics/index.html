Committee-scoped resource controls

  1. 01

    Admission & budget guard

    Configured provider rate budgets and token windows may constrain model calls in the broader source system.

  2. 02

    Proponent · Opponent · CoVe · Judge

    Verification is mandatory; cost constraints never authorise bypassing the checked-claim chain.

  3. 03

    Bounded recovery

    Retry or fallback is conditional and capped, with a safe deferral to human review when the budget is exhausted.

Implementation boundary: the reviewer implementation has token-economics modules — a rotating key pool, a rate limiter and a per-run cost rollup — but this public reference has no live provider usage, token log, provider latency or measured cash saving.
